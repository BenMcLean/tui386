TUI386.CSS

The Definitive All-in-one Graphical Tool-Kit for Micros and Terminals, now in plain CSS.

Every screen is a grid of 8x16 pixel character cells. One spacing unit is one column, two are one row. mb-2 is a blank line and px-1 is a space.

Use primitives like buttons, windows and menus. We handle rendering these abstractions on screen for you. GUI is Good.

About this demo

TUI386.CSS makes webpages look like 1980s DOS text-mode programs: the sixteen EGA colors, a bitmap font, square corners, no shadows or blur. It works as plain CSS, and has adapters for Tailwind, UnoCSS, daisyUI and Bootstrap.

This demo is one page written four times, each in that framework's own classes. You are viewing the Tailwind version; the framework links in the menu bar switch between them, and nothing on screen should change.

Source and docs: github.com/BenMcLean/tui386. Package: npmjs.com/package/tui386. Install with npm install tui386.

Type

Headings are all the same size. Bold is white, italic is cyan, links are yellow and invert on hover. Press AltF4 to quit.

Think of your software in terms of Windows, Icons, Menus, and Pull-Downs.
  • Lists are indented three columns
  • Nothing is rounded
  • Nothing has a blur
